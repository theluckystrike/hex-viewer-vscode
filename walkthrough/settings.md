# Settings

| Setting | What it does |
|---|---|
| `hexViewer.bytesPerRow` | 8, 16, 24, 32, 48 or 64 bytes in each row |
| `hexViewer.encoding` | Text column: ASCII, Latin-1, UTF-8, UTF-16 LE or BE, EBCDIC |
| `hexViewer.controlChars` | Show control bytes as a dot or as symbols such as ␀ and ␊ |
| `hexViewer.uppercase` | 4A or 4a |
| `hexViewer.fontSize` | Font size of the byte grid (0 = editor font size) |
| `hexViewer.copyFormat` | What Ctrl+C copies from the hex column |
| `hexViewer.littleEndian` | Byte order of the data inspector |
| `hexViewer.readOnly` | Turn off byte editing |

The toolbar changes bytes per row and the encoding for one tab.
